# Attic

Archived top-level files that are no longer primary entrypoints for the repository.

- `docs/`: legacy summaries, design notes, and one-off implementation writeups
- `outputs/`: tracked historical evaluation/report output directories kept for provenance, not daily work
- `samples/`: unreferenced sample data that was previously cluttering the repo root

Nothing in this directory is part of the main package/import path.
