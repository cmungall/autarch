# Benchmark Disagreement Catalog

This table records high-confidence cases where the observed disagreement is more plausibly due to GO/EC/RHEA alignment or local benchmark materialization than to classifier logic. It is intended as an issue-filing queue for external curation.

Reader-facing categories:
- `Truly unannotated candidate`: no GO support and no EC support.
- `GO-coverage gap`: the reaction already has EC support but is absent from the GO-labeled benchmark.
- `Local benchmark bug`: the disagreement comes from stale or incomplete local cache materialization.
- `True GO/EC scope conflict`: the reaction is classified, but GO and EC place it under different mechanistic parents.
